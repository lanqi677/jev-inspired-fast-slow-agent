【任务】排查一个"账号未同步"问题，并给出结论。

用户信息：姓名 张三，工号 123，邮箱 123@123.com

第一步，打开 SiteA 全部成员页：
  https://sitea.internal.example/project/#/team/TEAMID/team_setting/department/all_member
  在搜索框输入工号 123，点搜索，看结果条数。
    如果结果条数 > 0 → 说明账号在 SiteA 里已经存在，结论是「用户自身问题（工号存在，不是同步问题）」，结束。
    如果结果条数 = 0 → 在同一个搜索框改成输入邮箱 123@123.com，再搜一次。
        如果结果条数 > 0 → 点进这条记录的「查看详情」，看详情面板里的「工号」字段：
            工号为空 → 结论「问题1：工号为空，需要运维手动更新」，结束。
            工号不为空 → 看详情里的「姓名」和 张三 是不是同一个人：
                不是同一人 → 结论「问题2：邮箱重名，该邮箱属于别人」，结束。
        如果结果条数 = 0 → 进入第二步。

第二步，打开 SiteB 组织用户管理页：
  https://siteb.internal.example/ec/?locale=zh-CN#/user/org_user_management
  点右上角的「登陆」，在弹出的登录框里把「选择用户名」设为 用户名，在工号输入框里输入 123，点确定。
  在结果列表里点「详情」，看详情面板里的「邮箱」字段：
      邮箱 不等于 123@123.com → 结论「问题3：邮箱还未更新，上游系统问题」，结束。
      邮箱 等于 123@123.com → 再看「信息更新时间」字段：
          时间是今天 → 结论「正常：系统间更新间隔一天，等明天再看」，结束。
          时间不是今天 → 结论「异常：邮箱已正确但更新时间不是今天，需要人工确认」，结束。
